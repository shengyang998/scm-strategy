# Data and release availability

This distribution contains independently generated synthetic data and new software only. Empirical participant tables, raw pressure or motion files, identities, timestamps, scans, videos, private source hashes and private adapters are not included.

The public synthetic demonstration can be reproduced from its source equations, generator version, seed and parameters. This does not reproduce an empirical study's results. Reproducing empirical results requires separately authorized data, verified private format adapters, correct collection/QC/synchronization semantics and the study's frozen analysis configuration.

The source repository is [shengyang998/scm-strategy](https://github.com/shengyang998/scm-strategy). This 0.3.0 package does not upload or publish itself. The existing 0.2 commands remain available. No archival DOI, confirmed individual author list, ethics approval, institutional endorsement or data-sharing authorization is asserted. `CITATION.cff` retains a clearly documented collective project placeholder.

Authorized standardized bundles can run the complete fixed paper analysis and regenerate its tables and aggregate figures. Independent synthetic bundles exercise the same path without empirical data. Neither capability supplies the excluded raw-format adapters or grants access to the original data.
