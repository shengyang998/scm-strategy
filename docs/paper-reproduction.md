# Reproduce the paper workflow from standardized inputs

The `paper-study` workflow executes all **22 fixed analysis configurations**: 17 baseline-versus-motion predictive configurations and five morphology associations. It consumes a multi-table bundle after source decoding, synchronization, QC and feature extraction. Raw-format adapters remain private or separately licensed; this package contains no copied device readers.

Install the optional plotting dependency once:

```sh
uv sync --extra paper --frozen
```

For an already valid bundle, one command computes the models, main/supplementary tables and aggregate figures:

```sh
uv run --no-sync scm-strategy paper-study authorized_bundle --out runs/private-paper --report
```

Empirical input uses the frozen 2,000 bootstrap draws. All artifacts remain local and non-exportable; generated aggregates are not automatic permission to publish. A lower draw count is accepted only for explicitly synthetic input and is marked as a verification run.

## Independent synthetic full-bundle demonstration

```sh
uv run --no-sync scm-strategy paper-demo --out runs/paper-demo --participants 50 --primary-participants 25 --bootstrap 40 --skip-design-audit --report
```

This fast run exercises all 22 configurations. Forty resamples and an omitted design audit are an installation demonstration, not the full configured uncertainty analysis. Omit `--bootstrap 40 --skip-design-audit` for the full draw count and design diagnostics. Synthetic values are generated by `paper_synthetic.py` from independent equations and a fixed seed. No empirical rows, fitted empirical distributions or individual trajectories are sampled. The deterministic recipe can be checked with `verify_paper_recipe`; a label of `synthetic` alone is not verification.

The default teaching bundle has 25 primary participants, 50 extension participants, six sensitivity rows per primary participant, 30 paired trials, and 97 non-first pressure-repeat rows. These are a structural demonstration. They do **not** reproduce the empirical paper's numeric estimates. The generator includes independent body and outcome equations, trial noise and explicitly synthetic sensitivity perturbations. It does not pretend to perform raw-signal offset correction.

## Bundle and output roles

`bundle.json` declares `scm-strategy.paper-bundle/1`, the protocol, input kind, units and a safe relative file mapping. The shared reader/writer in `paper_bundle.py` validates:

- `primary`: one row per primary participant, with both specified motion summaries and all outcomes;
- `extension`: one pressure/body index row per participant, without imputed motion;
- `sensitivities`: the six fixed specifications for every primary participant;
- `pressure_repeats`: participant/trial-indexed speed and effective-area repeat measurements;
- optional `paired_trials`: motion repeat measurements;
- optional `cohort_profiles`: recorded sex, BMI, body/foot descriptors and **median speed across eligible pressure trials**, distinct from an extension index speed.

The schema permits explicit missing numeric values and unavailable rows with reasons. It does not silently impute them. Full descriptive reproduction requires `cohort_profiles`; when absent, T1/F1 report missingness instead of substituting an index trial. The producer must supply correct upstream interpretation and document its own source permissions.

The report contains:

|Artifact|Contents|
|---|---|
|`paper-report.json`|Versioned, labeled aggregate values underlying every table and panel. No individual case/eligibility rows.|
|`tables/T1_*.csv/.md`|Profile selection summaries, full observed-feature descriptions and recorded-sex counts.|
|`tables/T2_prediction.csv/.md`|The two primary-specification outcome comparisons, original-scale MAE and approximate bootstrap sensitivity intervals.|
|`tables/S1_prediction_sensitivity.csv/.md`|All 17 predictive configurations.|
|`tables/T3_morphology.csv/.md`|All five specified morphology associations.|
|`tables/T4_measurement.csv/.md`|Both cohorts' pooled/equal-person within-SD, first-last bias, approximate agreement limits and repeatability summaries.|
|`tables/S2_all_coefficients.csv/.md`|All available coefficient rows, including HC3 and participant-bootstrap intervals.|
|`tables/S3_numerical_diagnostics.csv/.md`|Fold/bootstrap matrix diagnostics when requested; absence is explicit.|
|`tables/S3_quality_counts.csv/.md`|Bundle counts and producer-supplied extraction/QC counts, separately labeled; missing upstream checks are not fabricated.|
|`tables/S4_calibration.csv/.md`|Computed independent synthetic calibration, or an explicit not-run row; never filled from the empirical paper.|
|`figure-data.json`|Machine-readable values actually plotted, with units and panel availability.|
|`figures/F1...F4.{png,svg}`|Aggregate coverage/selection, prediction, morphology, and measurement panels.|

Each report propagates `input_dataset_kind` and labels all CSV/Markdown/figures. `exportable` remains false. Synthetic reports are not relabeled as empirical findings; private empirical reports are not relabeled as synthetic. No individual scatterplots, waveforms or raw source provenance are included in the aggregate report. The full saved study object remains a separate private artifact because it includes case and prediction rows.

The fixed F1 selection panel retains its nine domains: age, height, mass, BMI, female proportion, body fat, bilateral navicular height and median eligible-trial speed. Their values come from the supplied cohort profiles; no additional fields are searched to produce larger differences.

Exponentiated log coefficients describe conditional geometric means. Original-scale mean predictions use training-only Duan smearing, with the stated residual-distribution assumption. HC3 does not correct heteroscedastic retransformation. Bootstrap intervals for ΔMAE are approximate sensitivity intervals, distinct from individual prediction intervals and substantive equivalence margins.

## Independently compute the calibration experiment

The paper's calibration has its **own** fixed Gaussian/lognormal data-generating mechanism. It is not the teaching cohort generator. Run it explicitly:

```sh
uv run --no-sync python -m scm_strategy.paper_report calibrate --out runs/paper-calibration --datasets 100 --bootstrap 200 --mc-training 20000 --mc-test 1000 --workers 2
```

This actually simulates two scenarios, each with 100 datasets of 25 people and 200 full group-bootstrap/LOSO repetitions. An independent normal-equation implementation estimates the expected MAE difference for algorithms trained on 24 people using 20,000 training sets and 1,000 new test people per set. It reports target Monte Carlo SE, center/point bias, Wilson coverage intervals, width and failed draws. It does not load stored empirical or manuscript calibration results.

To include the computed calibration panels C-D with the measurement panels A-B:

```sh
uv run --no-sync scm-strategy paper-study authorized_bundle --out runs/private-paper --report --calibration runs/paper-calibration/calibration.json
```

Without `--calibration`, F4 provides its complete A-B measurement panels and explicitly records C-D as **not run**. No zeros or saved paper numbers fill the gap. Reduced calibration sizes are useful smoke tests and are marked `matches_full_paper_calibration_sizes=false`. Favorable results from this limited mechanism do not establish real-data coverage or biological validity. Null strategy coefficients do not imply zero expected MAE difference between finite-sample fitting algorithms.

## Local-only browser payload

`build_local_view_payload(bundle, result)` and `write_local_view(bundle, result, path)` are separate from `export-web`. They produce `scm-strategy.local-study/1` with `local_only=true`, `exportable=false`, and `upload_allowed=false`, preserving `synthetic` versus `private_empirical`. The payload may contain standardized primary participant values and the necessary numbers for all 22 analyses. It excludes source paths, raw hashes, raw signals and arbitrary external links.

Its optional `configuration` is a fixed safe whitelist: seed, requested/executed bootstrap counts, full-draw flag, sample-size/condition-number gates, case speed caliper and window duration. A viewer must show omitted settings as unavailable rather than inferring them from the protocol identifier.

The CLI can save this local view alongside a report:

```sh
uv run --no-sync scm-strategy paper-study authorized_bundle --out runs/private-paper --report --local-view runs/private-paper/local-view.json
```

The included browser viewer accepts this payload only after the user explicitly chooses a JSON file. It parses and displays the file in memory, makes no upload or persistence request, and provides a control to discard the local data and return to the synthetic demonstration. See [the viewer instructions](../web/README.md). The `export-web` synthetic-recipe restriction and `web/data/demo.json` remain unchanged. Local payload generation does not authorize public hosting; browser accessibility/layout acceptance is separate from numerical tests.
